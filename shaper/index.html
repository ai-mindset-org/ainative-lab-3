1contract

сначала зафиксируй продуктовый контракт

Shaper работает, когда экран отвечает на один рабочий вопрос, показывает текущее состояние и оставляет проверяемый след. Четыре поля ниже входят в каждый бриф.

01 · question
что происходит?

один вопрос, который пользователь должен закрыть за один проход.

02 · action
что сделать?

одно следующее действие рядом с данными, которые его обосновывают.

03 · state
что активно?

инверсия показывает selection, focus, current и confirmed state.

04 · evidence
откуда известно?

источник, data window, timestamp, owner и версия видны на поверхности.

1

информация ведёт

геометрия показывает иерархию, связи и состояние. Декор не занимает отдельный слой.

2

один экран · один вопрос

каждая поверхность получает ведущий вопрос. Вторичные вопросы уходят в detail layer.

3

состояние объясняет себя

gate · silent, sync · stale, input · live читаются прямо в интерфейсе.

4

плотность управляется

высокая плотность допустима при стабильной сетке, табличных числах и ясных уровнях.

5

действие рядом с причиной

кнопка живёт рядом с сигналом, который запускает решение. Контекст сохраняется.

6

артефакт переживает автора

токены, примеры, handoff, source stamp и QA делают систему передаваемой.

LABELS

uppercase сообщает функцию

короткие micro-labels: SOURCE, OWNER, DATA WINDOW, LIVE. Основной текст остаётся lowercase.

ACTIONS

verb + object

open source, retry sync, publish guide, copy path. Пользователь заранее понимает эффект.

NUMBERS

единица рядом

24 files, 14m ago, 93% coverage, W1. Табличные цифры сохраняют ритм.

STATES

состояние текстом

live, stale, ready, blocked, silent, partial. Геометрия усиливает явный label.

ERRORS

cause + preserved + recovery

сообщение отвечает, что произошло, что сохранено и какое действие безопасно.

PROVENANCE

source + window + time

доверие строится из видимого происхождения данных и версии поверхности.

8qa

definition of done

Продукт, дизайн и переносимость проверяются отдельно. Один провал оставляет поверхность в draft.

product

  • ведущий вопрос записан одной строкой
  • primary action имеет понятный эффект
  • data window и freshness видны
  • empty, loading и error помогают продолжить
  • success подтверждается evidence
  • owner и lifecycle названы

design

  • paper #fff и ink #000 составляют основу
  • все structural frames имеют 1px
  • body lowercase, micro-labels uppercase
  • active state использует инверсию
  • сетка читается при высокой плотности
  • цвет имеет явную семантику, если добавлен

transfer

  • артефакт открывается без build step
  • токены и реальные примеры доступны
  • desktop, 760px, 390px и print проверены
  • keyboard focus остаётся видимым
  • source stamp содержит версию и дату
  • следующий owner повторил один сценарий
30-SECOND TEST
